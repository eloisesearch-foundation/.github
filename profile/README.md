# Eloisesearch Foundation

Eloisesearch Foundation is an open, developer-focused initiative exploring reliable, accessible, and interoperable search infrastructure for modern applications. The foundation aims to build on established search conventions while encouraging transparent engineering, practical integrations, and a strong ecosystem of tools and SDKs.

Our work prioritizes clear API contracts, documented compatibility, reproducible testing, and sustainable architecture. Projects under the foundation are intended to make search easier to adopt and operate without hiding important technical trade-offs.
